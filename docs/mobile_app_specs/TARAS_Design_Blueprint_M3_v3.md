# 🏎️ TARAS: Official UI/UX Design Blueprint & M3 Architecture (v3)

**Target Audience:** Gen Z, Gen Alpha, Hardcore F1 Fans.
**Design Philosophy:** "Google-Grade Bento Box." Clean, neutral Material 3 surfaces — like Google's own apps (Gmail, Maps, YouTube) — where the only color that "pops" is the F1 data itself: team accents, live indicators, and brand primary. The chrome disappears; the content is the color.
**Tech Stack:** Jetpack Compose, `androidx.compose.material3:material3:1.4.0`, Material 3 Expressive (`ExperimentalMaterial3ExpressiveApi`).

> **What changed from v2:** The v2 palette was algorithmically correct but felt "themed" — warm-tinted neutrals, saturated containers, a Racing Red seed that bled warmth into every surface. v3 pivots to Google's own approach: a **near-achromatic neutral backbone** (chroma ≤ 4 across the entire surface/outline family) with a restrained primary that only appears on interactive affordances, never on large fills. This matches how Google's own M3 apps feel — quiet, professional, and letting content (in our case, team colors and live data) be the visual star. The team palette is also updated to **official F1 team colors** per the user's definitive list.

## 1. 🎨 Material 3 Theming & Color Tokens

### 1.1 Design intent — "Google-app clean"

Google's own M3 apps share a pattern:
- **Surfaces are neutral gray**, not tinted by the seed. No warm/cool cast.
- **Primary is restrained** — used on FABs, active nav indicators, toggle fills, and text buttons. Never used as a large background fill.
- **Containers are subtle** — `primaryContainer` is a soft, desaturated wash, not a saturated slab.
- **The surface-container ladder** provides hierarchy through lightness steps alone, not hue shifts.

TARAS v3 follows this exactly. The seed color (`#E10600`, Ferrari-grade racing red — the sport's own brand red) informs only the primary accent. The neutral backbone is essentially achromatic — true grays in dark mode, true warm-grays in light mode — generated by setting the HCT neutral source chroma to ≤ 4.

## 2. ✍️ Typography Scale (M3 Expressive)

M3 Expressive doubled the type scale: **15 baseline styles + 15 "Emphasized" counterparts** (same Display/Headline/Title/Body/Label × Large/Medium/Small grid, heavier weight, meant for selection and focal moments).

*   **Font Family:** `Google Sans` (for the Google-app feel) or `Outfit` (open-source fallback, geometric sans) for UI text. `Roboto Mono` for timing/telemetry data.
*   **`displayLargeEmphasized`:** 57sp, heaviest available weight. The "Next Race" countdown — the one place a maximal type moment is earned.
*   **`headlineMediumEmphasized`:** 28sp. Screen titles, active tab states only.
*   **`titleMedium`:** 16sp SemiBold. Card titles, driver names.
*   **`bodyMedium`:** 14sp Regular. Descriptions, RSS article summaries.
*   **`labelSmall`:** 11sp Medium, Monospaced (`Roboto Mono`). Timing gaps, RSS dates, points.

```kotlin
@OptIn(ExperimentalMaterial3ExpressiveApi::class)
Text("FP1 in 02:14:59", style = MaterialTheme.typography.displayLargeEmphasized)
```

## 4. 📱 Compose Architecture & Navigation Graph

Single-activity architecture, Material 3 `Scaffold`.

**Global `Scaffold` Structure:**

*   **`topBar`:** `CenterAlignedTopAppBar`
    - `containerColor = MaterialTheme.colorScheme.surface` (scrolled state: `surfaceContainerHighest` via `TopAppBarDefaults.pinnedScrollBehavior()`). No custom glassmorphism — use M3's built-in scroll-aware color change for the Google-app feel.
    - Displays "TARAS" wordmark or current session status.

*   **`bottomBar`:** M3 `NavigationBar`
    - `containerColor = MaterialTheme.colorScheme.surfaceContainer` — this is exactly what Google's own apps use, not `surface`.
    - Active indicator: `NavigationBarDefaults` (M3 handles the indicator fill automatically using `secondaryContainer` — don't override).
    - Active icon: `colorScheme.onSecondaryContainer`. Inactive icon: `colorScheme.onSurfaceVariant`.
    - Items: 🏠 Paddock (Home), 🏆 Grid (Standings), 📅 Calendar, 👤 Drivers.

*   **`content`:** The active `NavHost` destination.

```kotlin
// Theme.kt
@Composable
fun TarasTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    content: @Composable () -> Unit
) {
    val colorScheme = if (darkTheme) TarasDarkColorScheme else TarasLightColorScheme

    MaterialTheme(
        colorScheme = colorScheme,
        shapes = TarasShapes,
        typography = TarasTypography, // define with Outfit/Google Sans
        content = content
    )
}
```

*   **Item 4+ (span 2): "Latest from the Paddock" (RSS Feed).**
    - `LazyRow` of News RSS Cards
    - `ContainedLoadingIndicator` while fetching (uses M3 Expressive loading composable)

### Screen 2: "The Grid" (Standings)

**Compose Blueprint:** `Column` with `PrimaryTabRow` + `HorizontalPager`.

*   **`PrimaryTabRow`:** "Drivers" / "Constructors" tabs.

*   **Driver List Item:**

## 6. 🧩 Core Component Design Specs

### A. "News RSS Card"

*   `ElevatedCard`, `width(280.dp)` × `height(200.dp)`, `clip(TarasShapes.large)`.
*   `containerColor = MaterialTheme.colorScheme.surfaceContainer`.
*   `tonalElevation = 1.dp` — M3 handles the tonal shift via `surfaceTint`, giving a subtle lift.
*   Top 60%: thumbnail (`AsyncImage`, `ContentScale.Crop`). Bottom 40%: title (`titleMedium`, 2 lines, ellipsis).
*   Timestamp in `labelSmall`, `onSurfaceVariant`. Live dot: `primary` (small 6dp circle).

### B. "Driver Bio Card" (Drivers Grid)

*   `OutlinedCard`, `fillMaxWidth()`, `clip(TarasShapes.medium)`.
*   `containerColor = MaterialTheme.colorScheme.surfaceContainerLow`
*   `border = BorderStroke(1.dp, MaterialTheme.colorScheme.outlineVariant)`
*   **Team accent gradient:**
    ```kotlin
    Modifier.background(
        Brush.horizontalGradient(
            listOf(
                Color.Transparent,
                LocalTeamColor.current.accent.copy(alpha = 0.12f)
            )
        )
    ```

    Alpha kept at `0.12f` — enough to tint the card edge without competing with the neutral surface.

### C. "Team Standing Row" (Constructors Tab)

*   Full-width Row, `surfaceContainer` background.
*   Left: 4dp-wide vertical strip in `LocalTeamColor.current.accent` — the "racing stripe."
*   Constructor name: `titleMedium`, `onSurface`.
*   Points: `labelLarge`, `primary`.
*   This is where the team color really sings on the neutral backdrop.

## 7. ✨ Micro-Interactions & Motion

M3 Expressive's spring-physics `motionScheme`:

```kotlin
val motion = MaterialTheme.motionScheme
val pressScale by animateFloatAsState(
    targetValue = if (pressed) 0.98f else 1f,
    animationSpec = motion.fastSpatialSpec(),
)
```

1.  **Shared Element Transitions:** Driver Card → Deep-Dive hero (`SharedTransitionScope`).
2.  **`AnimatedVisibility` on Scroll:** `fadeIn() + slideInVertically(initialOffsetY = { 50 })`, driven by `motion.defaultSpatialSpec()`.
3.  **Bento Press Effect:** `Modifier.clickable(indication = ripple())` — use M3's default ripple (which reads from the theme) + `motion.fastSpatialSpec()`-driven `scale(0.98f)`.
4.  **Shape morph on live state:** Pit Wall shortcut morphs `Cookie9Sided` → `Circle` when a session is live.
5.  **Nav bar indicator:** Let `NavigationBar` handle its own indicator animation — M3 Expressive uses a spring-driven pill expansion. Don't override.
